Try it: upload a clip

Drop in a short broadcast-style clip, pick the sport, and the pipeline rebuilds the play in 3D: players as meshes, court/field and ball fitted, camera recovered. When it finishes you get the interactive viewer, rendered videos and a zip. This test version runs on the owner's Mac, so jobs take about 1–3 minutes per second of footage, one at a time.

Checking the worker…

The worker isn't reachable

This page sends your clip to a processing server. In this test version that server runs on the owner's computer at http://127.0.0.1:8765. If it's yours:
  1. Start the worker: 
    "/Users/alex/Desktop/Projects/Internal/Sports/service/start.sh"
  2. Reload this page. Chrome and Edge will ask to let this site access devices on your local network: click Allow (if you dismissed it, use the site-settings icon left of the address bar → Local network access → Allow).
  3. No prompt, or using Safari / another browser? Open the same page served by the worker itself, which always works: http://127.0.0.1:8765/
  4. Using a tunnel (e.g. Cloudflare Tunnel) so other people can reach it? Add ?api=https://your-tunnel-host to this page's URL.
